# Ford Kall 1.2.1

- No APK e na PWA instalada, o botão “Baixar app” agora é “Aplicativo”, com acesso às atualizações. Não oferece instalar novamente nem mostra downloads de outras plataformas.
- A interface de aplicativo é preservada ao entrar por link de sala, navegar para a home e recarregar a janela.
- No navegador comum, os downloads para Android, Windows e macOS continuam disponíveis.

O APK usa a mesma assinatura da versão 1.2.0 e pode ser instalado por cima dela. O conteúdo web também recebe a correção pelo atualizador da PWA, sem reinstalar o APK. Esta versão não muda as permissões nem as limitações de mídia do navegador no Android.
