# Ford Kall 1.1.1

- Excalitower removido completamente da central de jogos, da call e do aplicativo.
- Removidos o editor, as bibliotecas, os ícones e os mecanismos de abertura/sincronização dessa atividade.
- O Gartic continua funcionando com um canvas próprio e leve: pincéis, cores, desfazer, limpar e desenho compartilhado.
- Os demais jogos, a call e os perfis foram preservados.

Windows Setup recebe a atualização pelo aplicativo. Windows Portable e macOS estão disponíveis nos arquivos deste release; no macOS, a instalação continua manual.

Atualize os participantes para esta versão antes de uma nova partida de Gartic, pois o protocolo de desenho foi simplificado. O código removido continua recuperável pelo histórico do repositório.
